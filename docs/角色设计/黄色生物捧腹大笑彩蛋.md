# 黄色生物：捧腹大笑彩蛋

## 触发

收到酒并成功结算后，回到酒馆显示顾客反馈时检查：

- 顾客为 `yellow_creature`。
- 本杯制作评分 `craft.score >= 90`（不是总评分）。
- 剧情模式：该次锁定需求评价 `review.status == scored` 且 `review.satisfied == true`，包含当次短期偏好。
- 调酒模式：订单 `free_settlement.matched == true`。
- 同一张送酒记录此前没有播放过。

阈值集中在 `scripts/yellow_laugh_rules.gd` 的 `MIN_CRAFT_SCORE`。

## 表现与流程

1. 原有收入、评分照常结算。
2. 回到主页，黄色生物切换为捧腹笑姿，肩膀和肚子随音频包络颤动，播放 8 秒笑声。保持人物在吧台后方的裁切。
3. 对话框显示“（它抱住肚子笑弯了腰，连帽子都跟着一颤一颤的。）”，暂时不提供反馈选项和送客操作。
4. 动画结束恢复原人物与原反馈，AI 请求可在后台继续；未配置 API 时沿用现有本地反馈。
5. 切换页面、客人、模式或退出场景时，音频随节点停止。切回不重播。

播放前先把 `yellow_laugh_played: true` 写入该杯的 CustomerService 结算记录；写入失败时回滚标记并跳过动作，正常反馈仍可用。沿用旧存档，无需重新开始。

## 文件

- `scripts/yellow_laugh_rules.gd`：触发判定。
- `scripts/yellow_laugh.gd`、`scripts/yellow_laugh.gdshader`：透明图片的实时网格动画。
- `assets/guests/reactions/yellow_laugh.png`：确认的笑姿。
- `assets/guests/reactions/yellow_laugh_levels.json`：240 个音量包络采样。
- `assets/audio/sfx/yellow_laugh.wav`：8 秒笑声音频，SFX 音量控制，播放增益 -4 dB。
- `tests/verify_yellow_laugh.gd`：隔离测试，需要 `--laugh-test` 和外部测试存档路径。
