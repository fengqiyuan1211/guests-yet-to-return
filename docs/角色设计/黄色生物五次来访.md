# 黄色生物：五次简短来访

更新日期：2026-10-15。游戏显示名仍为“黄色生物”，角色 ID 为 `yellow_creature`。

## 对话

每次开场相同：

- 客人：我是奶龙
- 玩家唯一选项：我才是奶龙
- 选后显示以下括号旁白。它不亲口说点单内容；所有第三人称统一使用“它”。

1. （它似乎想要一杯**莫吉托**。）
2. （它似乎想喝**甜一点、没那么酸**的。）
3. （它似乎想喝**酒味轻一点**的，甜味和酸味照平常就好。）
4. （它似乎想喝**酸一点、少甜一点**的。）
5. （它似乎又想喝**第一次点的莫吉托**了。）

JSON 使用 `[b]…[/b]`，由现有游戏富文本显示加粗。括号内是对它意图的观察，不增加另一位旁白人物，不改现有对话框。

## 数值

基准为现有 `mojito` 标准杯：酒感 40、甜度 35、酸度 45、苦度 0。这些是游戏感官值，不是酒精体积分数。

| 来访 | 酒感 | 甜度 | 酸度 | 苦度 | 相对基础值变化 |
|---|---:|---:|---:|---:|---|
| 1 | 40 | 35 | 45 | 0 | 无 |
| 2 | 40 | 50 | 30 | 0 | 甜 +15、酸 -15 |
| 3 | 25 | 35 | 45 | 0 | 酒感 -15 |
| 4 | 40 | 25 | 60 | 0 | 甜 -10、酸 +15 |
| 5 | 40 | 35 | 45 | 0 | 回到基础值 |

每次从基础值计算，不继承前一次临时变化。四项权重仍为 1、容忍值仍为 5，不新加 Buff 加分。

按照本次允许调整基础偏好并对齐已有酒的要求，取消旧“无酒精”限制；莫吉托含白朗姆酒，保留此限制会导致标准杯被拒收。新旧两套需求配置与人物展示一起更新。

## 进度与兼容

- 第一份仍用 `repeat.json` 和 `yellow_creature_repeat`，保留旧节点 `start` / `handoff` 和选项 ID。
- 第 2–5 份为 `02.json` 至 `05.json`。
- 这次暂按五种需求设计。第五次以后复用第五份；不增加复杂故事和隐藏事件。
- 同一次接待中点击对话不会跳到下一次需求；切页和重开不重新计算已锁定的订单。
- 每轮确认旁白后按既有章节规则记录完成，客人继续留下等待调酒，送客后才进入下一次。
- 原来反复说固定梗没有累计完成轮次，因此升级后从第一次新需求开始，保留认识状态和历史。
