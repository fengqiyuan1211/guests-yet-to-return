# 像素风第二轮修订说明

日期：2026-10-18  
项目：致未归的客人 / Godot 4.7.2  
本轮针对已接入的 B 档美术进行修正。正式存档、配方数值、库存规则和角色剧情进度保持原有逻辑。

## 1. 开场 CG 自动播放

- 序章对话框增加“自动播放：关 / 开”按钮；鼠标点击或按 **A** 切换。
- 默认关闭。开启后先完成逐字显示，再按文字长度停留约 **2.5—6 秒**，随后进入下一句。
- 鼠标点击或空格仍可提前显示全文、继续下一句；手动推进会重置等待时间。
- 邮件阅读、剧情选项、教学入口，以及开业衔接中的签收、留水、备料、购物和开门，由玩家操作，不会被自动播放跳过。
- 历史记录、邮件阅读窗口、开业准备和商店弹层打开时暂停自动推进。游戏窗口失去焦点时也暂停；回来后重新计时。
- 自动播放是当前场景的播放状态，没有写入正式剧情存档，也不改变已读记录和分支选择。
- 开业衔接演出共用同一计时器。老板娘独立交谈窗口继续保持原来的手动推进方式。

实现：`scripts/story_autoplay.gd`、`opening_story.gd`、`opening_departure.gd`。

## 2. 本轮处理的界面显示问题

- 备料柜商品名称与库存数字分行，卡片高度增加，长名称最多两行，防止与库存数字挤在一起。
- 摇壶和量酒器上移；滤冰器默认位置收在提示栏之上。同步调整合盖位置、阴影与倒酒出液点。
- 开场自动播放按钮与原有继续按钮分别占用独立位置，不挤占对白区域。
- 开场按钮和面板边框加粗，解决缩放后部分细边消失的问题。
- 宽屏剧情区域外使用深色底，避免露出默认灰底。
- 检查了 1280×720、1024×768、1280×800 和 1280×540 下的工作台及剧情布局。相关控制区在可见范围内。

## 3. 半身立绘

本轮重新制作老板娘、老霍克、艾达、米洛的独立透明立绘，以原先非像素版本为造型参考：

| 角色 | 保留的主要特征 |
| --- | --- |
| 老板娘 | 白发与辫子、青色围巾、罗盘胸针、马甲与围裙、手中纸张 |
| 老霍克 | 帽子、灰胡须、浅色衬衫、棕色马甲、领巾和叠放的双手 |
| 艾达 | 辫发、帽子、蓝色衬衫、红色围巾、扶帽动作 |
| 米洛 | 帽子、胡须、浅色衬衫、马甲与红色领巾 |

主画面显示至腰部和手部。对话框中的小头像仍单独裁切，避免把主立绘误用成头像。

**小线、黄色生物的原立绘和专属小游戏素材保留。** 已与接入像素风之前的保护清单比较，22 个文件内容一致。

## 4. 工作台、瓶装材料与成品酒

- 工作台背景细化木纹、桌垫和光照颗粒，保留原场景构图与器具位置关系。
- 五种杯具及摇壶、量酒器、滤盖、顶盖使用更细的像素素材。玻璃轮廓和金属高光保留原外观。
- 18 种瓶装酒与液体原料，以原素材的瓶型、酒标、封口和颜色作为重绘依据。
- 六款基础成品酒重绘：遗言、回响、莫吉托、金汤力、长岛冰茶、曼哈顿。保留原杯型、装饰和酒体印象。
- 红味美思和莫吉托额外生成独立素材，避免图集裁到瓶盖或薄荷顶端。
- 液体、冰块、分层、气泡和操作动画仍由现有运行逻辑动态绘制。没有把整屏压缩或加模糊滤镜。
- 配方、容量、用量、库存与评分数据没有因换美术而调整。四种成品杯另做了液面贴合实机检查。

新增资产目录：`assets/pixel_b/v2/`。原素材仍保留。  
通过 `pixel_art.gd` 优先选择修订版资源；素材没有修订版时继续使用原 B 档资源。

## 5. DIY / 研发入口

恢复原有书桌式入口，再对书桌进行像素重绘：

- 左侧摊开的笔记本：自由 DIY，可点击书页或“开始试调”。
- 右上方旧手稿：传说配方研习。
- 右下方配方盒：我的配方。

恢复对应实物的点击范围、书页倾斜角度和说明位置；书桌上的文字与按钮仍为可点击的游戏 UI。研发试调、保存配方、历史版本和重新进入半成品的逻辑沿用现有实现。
