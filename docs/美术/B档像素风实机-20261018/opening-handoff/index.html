交互和进度处理

短按空格或点击继续；签收、递水、翻牌有完成反馈。长按空格 3 倍速仍保留，新加入的进店演出也支持。

跨场景时会先接住画面，并等待空格或鼠标松开后再恢复输入，避免一次按键误触下一页。正常开业直接进入酒馆；回看序章结束仍返回开始界面，按钮会明确说明。

演出期间暂停营业计时。购物仍使用真实库存和金币；教学杯不消耗仓库，演出不会重复结算。中断入场后恢复同一位客人和对话进度。
