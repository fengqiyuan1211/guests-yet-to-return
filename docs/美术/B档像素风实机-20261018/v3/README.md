# 工作台器具像素重绘 V3

2026-10-19，根据确认的 V3 概念图接入。瓶身、瓶标、器具结构沿用原造型，以较细的像素轮廓和分段色块呈现金属、玻璃与木质。

## 接入内容

- 18 款瓶装材料：金酒、绿查特、樱桃利口酒、白朗姆、伏特加、龙舌兰、君度、黑麦威士忌、红味美思、苦精、蓝橙、午夜蓝、汤力水、苏打水、可乐、糖浆、青柠汁、柠檬汁。
- 5 种玻璃器具：高球杯、搅拌杯、鸡尾酒杯、碟形杯、球形杯。
- 7 件金属或手持器具：摇壶身、滤盖、顶盖、量酒器、吧勺、轻压棒、滤冰器。
- 各素材使用独立 AtlasTexture，真正透明背景；杯内动态酒液继续由现有系统绘制。
- `scripts/pixel_art.gd` 优先读取 V3，其他物品自动沿用 V2 或原 B 档资源。商店、仓库和备料柜通过共享物品入口使用同一套瓶型。

本次没有改写配方、容量、库存、评分、剧情、存档或交互状态。背景和布局沿用已有版本。小线与黄色生物保持原美术；手帐的普通角色列表继续使用此前确认的像素 Q 版头像。

## 文件与生成记录

- 最终素材目录：`assets/pixel_b/v3/`，包含 7 张透明素材图和 30 个 `.tres` 资源。
- `atlas.json`：每个物品与图集裁切范围的对应关系。
- `generation.json`：完整提示词、输入参考、生成原文件与项目保存路径。
- 生成方式：内置 `image_gen.imagegen`，基于已确认的风格板和原有造型参考，生成透明像素素材。没有使用 CLI/API fallback，也没有对图片做机械降采样。
- 旧版和原始素材均保留，可通过素材优先级切换回去。
