# 配方计量与用冰规范

## 已统一内容

- 检查了五款经典、教程《回响》、四款角色特调及DIY保存／读取流程。
- 液体使用 ml，糖等称重材料使用 g；计件材料使用 piece，薄荷枝使用 sprig。数字与单位分开保存。
- 配方用量与库存扣减量采用相同单位。曼哈顿苦精由1 dash改为1 ml，沿用此前已经在操作、评分、库存中使用的换算，不改变消耗或售价。旧写法在source_quantity中追溯。
- 片／块／颗／枝只在界面显示，按材料确定；不再把所有piece都显示为“颗”。
- 冰不进入ingredients，不影响点亮材料进度，不扣原料库存，也不计售价。
- 所有冰行都明确冰型、用途、克数。《回响》补为制作冰；角色特调的sku_ice_cube统一为sku_ice_standard_cube。
- 工作台、图鉴、选酒、研发、纪念酒单使用统一显示方法。碎冰不再因为缺少SKU被显示成方冰；预览也保留真实冰型。
- 新DIY保存库存标准单位及出品冰信息，同用途同冰型合并显示。旧DIY通过副本兼容读取，历史成品记录不改写；旧记录未明确用途的冰按其原来的“成品杯实际用冰”语义补为出品冰。

## 标准字段

原料例子：
```json
{"sku_id":"sku_angostura_bitters","name":"安格仕苦精","amount":1,"unit":"ml","inventory_amount":1,"inventory_unit":"ml","conversion_factor":1,"required":true,"use":"配料"}
```

冰例子：
```json
{"name":"标准方冰","kind":"cube","sku_id":"sku_ice_standard_cube","amount":100,"unit":"g","use":"出品冰","inventory_policy":"excluded_from_ingredient_inventory"}
```

- kind只用cube或crushed；use只用制作冰或出品冰。
- 制作冰用于摇和／搅拌，过滤后留在源容器；出品冰留在客人的杯中。
- 统一以g记录，份／块／铲是操作提示：每份50 g；方冰每份4块，每块12.5 g；碎冰每份1铲。不要把150 g写成150份或把碎冰当方冰计块。
- UI示例：`出品冰 · 碎冰 150 g（3 份）`。
- 工具类为scripts/recipe_quantities.gd；数据在data/cocktails/catalog.json和data/research.json。codex_metadata与示例记录一并更新。
- SQLite为JSON的校对副本，已同步6款目录酒。源表行号-1明确表示游戏内原创记录无工作表行号，不是实际Excel行号。

## 兼容与验证

所有10款现有配方的库存单位、实际消耗与冰总重量逐项对照保持一致；没有重调配方、口味或价格。DIY新增规范字段，不改旧存档和已结算成绩。DIY目前记录成品杯的实际出品冰，过滤掉的制作冰仍由操作笔记保留，不伪造为成品冰。

测试：单位与DIY保存150项；工作台加冰19项；五款经典实际制作、库存、口感及结算356项。沿用独立临时存档，不动玩家进度。无界面运行仍可能出现系统字体及退出资源告警。
