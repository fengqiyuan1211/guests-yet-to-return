## 场景定位

商店是一处可以从酒馆前往的独立港口地点，暂称“港口货栈”。海面、靠岸货船、码头和售货柜台构成场景。船运让不同产地的原酒和后续新货有一个自然的来源。

保持现有西部 2D 画风：棕色木头、黄铜细边、牛皮纸、墨迹装饰。港口加入低饱和蓝绿色海面，与酒馆形成环境变化。光线柔和，物品保持已经确定的哑光手绘风格。

概念稿在此文档旁的 `design/shop/harbor-shop-shelves-v0.2.png`。图中数字只作排版示例，不回写商品价格。

**2026-10-01 运行版更新：** 本文余下内容保留早期概念。商店现只售原酒、配料、装饰品，共 22 件；六种器材、四种杯型默认拥有，不售卖。实际场景为 `scenes/harbor_shop.tscn`，已连接金币、统一库存、存档与图鉴。价格采用独立试用配置，并非源表价格。换页动画期间锁定购买，切换分类能取消旧动画。

## NPC 造型

白发少女商人以年轻成年人的形象呈现。银白色侧辫、浅色卷袖衬衫、棕色马甲或围裙、低饱和蓝绿色围巾，搭配腰包和小铜质指南针饰物。衣着利落，适合搬货、记账与售货。

NPC 站在柜台后，手搭柜台或拿货单，避免脚踩柜台与人物悬浮。她的轮廓清楚，船仍能从肩后和上方看见。暂不确定姓名和背景故事，也不加入现有五位酒馆客人的随机池。

初始招呼：“船刚靠岸，今天的货都在这儿了。”

后续可做眨眼、轻微呼吸、围巾摆动和交货动作。场景可增加水面起伏、帆布轻晃、海鸟，首版保持克制。

## 货品陈列

分类与现有商品库完全一致：

1. 原酒
2. 配料
3. 装饰品
4. 器材
5. 杯型

原酒包含全部含酒的商品，包括利口酒、味美思和苦精。冰块不列为商店原料。

首版每页六件商品，每层三件。瓶子、配料、装饰与器材使用已有独立透明图片，按比例摆上货架。商品的名称和价格写在小吊牌上，库存放在底部购买单中，减少货架上的文字。

分类选中用木牌下划线。选中商品通过吊牌上的细墨线或小印章表示，购买按钮在指针停留、点击或触控操作时反馈。未购入的商品也展示彩色图片，便于认识和挑选。商品是否解锁与是否有库存分别记录。

不同分类的摆放方式：原酒立在木板上；瓶装配料正常摆瓶，糖和薄荷可配小筐或托盘；装饰品放浅盘或小篮；器材按比例摆在托盘上，细长吧勺可挂起；杯型统一落在货架面上。筐、盘与挂钩属于展示装饰，不额外加入商品库。

底部页码与左右翻页区域允许触屏点击。分类筛选后只显示该类商品，并回到第一页。

## 选中商品与购买区

点一件货品或它的吊牌后，在货架下方的购买单显示：

- 商品名称、两三个简短风味或用途词。
- 每份规格和当前库存。
- 数量减号、数量、加号。
- 合计价格与“购买”。
- 首次购入时的“首次购入可点亮材料”小字提示。

常规流程：选择分类 → 点商品 → 调数量 → 购买。重复补货直接在同一区域完成。

### 各类商品的显示差异

| 库存类型 | 展示示例 | 购买操作 |
| --- | --- | --- |
| 按包装消耗 | 库存 2 瓶，本瓶余量 100 ml | 可反复购买完整包装 |
| 按件消耗 | 库存 8 份 | 可反复购买，显示每包包含的件数 |
| 永久器材或杯型 | 未拥有 / 已拥有 | 隐藏数量选择；未拥有时可购买一次，拥有后显示“已拥有”并禁用购买 |

数量为玩家购买的包装数，具体增加多少件由商品的 `package.purchase_quantity` 决定。按瓶记录的数量包含正在使用的一瓶。补货时不改动当前瓶剩余量。

购入后显示简短反馈，例如“这瓶给你装好了。”，并刷新金币、库存和首次解锁提示。材料耗尽后仍保持已解锁。

价格未配置的商品在真正接入前需要确定价格；当前数据中的 `null` 不视为免费，也不填成假数据。读取真实商品数据进行预览时显示“待定”并禁用购买。当前只有 7 件商品有示例价格，其余仍待配置。

## 横屏与触控

桌面概念稿保留左侧场景约 44%、右侧货架约 56%。更窄的横屏给货架更多空间，减少场景宽度与对话框高度，必要时改为每层两件商品。保留 NPC 面部、名称、价格和购买区。

所有商品点击区域覆盖完整陈列位与吊牌。瓶子约高 180–210 逻辑像素，薄荷和装饰约 90–120，小器材约 120–170，保持比例并底部居中，避免把薄荷放大成酒瓶。长商品名可换行。

商店填满现有 PageHost，沿用 Stage 的整体缩放，内部不重复缩放。

返回、翻页、数量和购买操作在实际屏幕上的点击尺寸应至少约 44 × 44 点。购买按钮可用约 96 逻辑像素高，最终在 800 × 450 和手机横屏中检查点击和文字大小。信息不依赖悬停才能看到。

## 后续 Godot 接入

现有入口为 `shop`，目前仍是通用预览页。后续可注册独立的 `scenes/shop.tscn`，继续复用 Navigation 的返回流程。

素材分层：

1. 港口背景：独立无 UI 图片，保留天空、船、水面、货棚和柜台的空间。
2. 白发少女：透明底人物，单独绘制与定位。
3. 空货架：独立绘制，保留两层木板与背板。吊牌与购买单纸张可复用现有牛皮纸风格。
4. 商品：直接复用 `assets/art/supplies/` 的现有透明素材和 Texture 资源。
5. 所有分类、名称、库存、价格、数量、页码、对话和按钮：Godot 控件生成。每个商品位用透明 Button 覆盖图片和吊牌；图片与装饰忽略鼠标事件，点击只由商品位接收。

概念图用于看设计。最终文本和交互不烘焙进背景图。

已有数据和接口：

- `data/supplies/catalog.json`：32 件商品，分类、图片、包装规格与存储方式。
- `data/supplies/initial_state.json`：初始解锁与库存状态。
- `scripts/supply_catalog.gd`：商品查询和图片资源。
- `scripts/supply_inventory.gd`：购买、消耗、解锁、序列化和恢复。
- `docs/物品接口标准.md`：与调酒板块协作的字段标准。

当前库存类尚未接入主存档与金币交易。正式购买应由统一交易入口处理扣金币、库存变更与存档；商店和调酒工作台读取同一份库存。只切换 UI 分类不改动存档。

## 制作顺序

1. 确定场景、人物、货架与购买单布局。
2. 分别生成无 UI 港口背景、透明 NPC、空货架和购买单底图。
3. 在 Godot 搭建界面，复用 32 件商品与图片，实现分类、选中、翻页和数量交互。
4. 确定价格，连接金币、统一库存、首次解锁与主存档。
5. 增加轻量场景动画和交易反馈。
