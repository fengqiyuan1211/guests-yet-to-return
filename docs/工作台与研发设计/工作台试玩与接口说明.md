# 工作台试玩与接口说明

2026-10-02 · Godot 4.7.2 · 第一人称实景版 v0.6 · 直接倒料与拖动工作台

## 试玩入口

- 正常运行游戏：提前开始营业 → 前往调酒台。
- 独立试玩：在 Godot 打开 `scenes/workbench.tscn`，按 F6。返回会回到主页。
- 本版仅独立试作，不交付顾客、不收款、不写酒单、不授予配方解锁。研发入口和保存配方尚未接入。

## 当前画面与操作

用户确认的方向：无手第一人称、近距离真实调酒桌、左上订单纸条、右侧备料柜，保留暖色手绘酒馆风格。

背景、19 个器具／材料主体（含独立高球杯）与原生 Godot UI 分层，交互器具不是烘焙在一张背景里的静态图案。右侧有基酒、配料、装饰、杯子、冰块、器具六类。

1. 从右侧把材料直接拖到成品杯、量酒器、搅拌杯或打开的摇壶，松开进入倒料。也可以点击材料先摆到桌面，再拖桌上瓶子。桌面最多五款不同材料，同款不重复占位；第六款不会挤掉已有物品。拖回备料柜收起，已取酒液保留。摆瓶、收瓶不扣材料。
2. 瓶子靠近所选容器并倾斜，显示曲线酒流与剂量指针。默认使用配方剂量；选中瓶子后滚轮按 5 ml 调整下次目标（试作范围 5–60 ml）。黄金区间按空格得到目标量，偏早／偏晚得到实际偏差，超时取上限。Esc 取消尚未提交的倒料，指针阶段的杯内酒液只作预览。
3. 空格落定后，实际量进入拖放目标容器，只扣一次原料。经量酒器制作时，把量酒器拖到制作容器，松手转移；转移不再扣料。液面、颜色随内容改变。倒料完成后连续按空格不会直接出杯；出杯需要明确点选成品杯或拖杯。
4. 右上角固定成品杯；搅拌杯与吧勺在左侧，摇壶、壶盖和量酒器在中间。滤冰器、轻压棒收在右侧器具菜单；用时拖到目标容器。这里的拖拽用于制作操作，尚非自由摆放家具。
5. 冰块直接拖到制作容器，青柠角直接拖到成品杯。仍兼容先点击选择再点容器。落冰有下落反馈，玻璃容器内的冰随液面位置变化；冰不进入原料库存。
6. 滤盖、顶盖拖到摇壶合盖，也可以点击开合；选中摇壶后空格开合盖。按住盖好的壶身拿起，鼠标上下推拉表现前后摇和。松手或失焦平滑放回；左右移动与静止持握不累计时间。
7. 吧勺、轻压棒拖到对应容器切换技法；按住杯口画圈搅拌，按住容器上下拖动轻压。拿杯出杯时拖杯脚，避免与杯口技法混淆。滤冰器从菜单拖到摇壶／搅拌杯，直接过滤至右上成品杯；摇壶需先开盖，冰留在源容器。
8. 点击右侧杯型立即替换桌上杯子，保留液体、冰和装饰，不重复取料。本原型各成品杯暂共用 300 ml 容量；正式不同杯容量与换杯损耗尚未接入。
9. 点选成品杯后按空格出杯，或拖杯脚到拖动时出现的“松手出杯”区。没有额外出杯确认按钮；其他容器有余量时，底部事先提示会记为弃置。结果页空格另起一杯，Esc 返回桌面。
10. 底部仅显示动态下一步提示、动作反馈和时长，不摆操作选项。返回、记录、重做移到上方；快捷键分别为 Esc、R、N。重做涉及丢弃，保留一次空格确认，Esc 可取消。
11. 返回、切页与退出恢复保留半成品；取消未提交倒料不扣料，已提交材料在丢弃与重做时不退回。新杯保留上一杯记录。

## 原型范围

“码头试作 / Dockside Practice”是交互测试配方，不是故事第一杯，也不是正式莫吉托。30/20/10 ml、四秒指针、黄金区间、练习库存及容量都是试作配置，不是平衡定稿。

目前基酒为金酒、朗姆、伏特加；配料为青柠汁、糖浆、苏打；装饰为青柠角；两种杯型、两种冰型及六种常用器具。高球杯与搅拌杯使用不同的正式素材；桌面、备料柜和供应品展示共用同一套美术资源。尚未模拟真实液体物理、融水、偶然洒漏、固体萃取、成本或味觉评分，结果也不自动保存为 DIY 配方。

## 模块与衔接

| 文件 | 职责 |
| --- | --- |
| `scenes/workbench.tscn` | 独立运行或接现有 PageHost |
| `scripts/workbench.gd` | 订单、备料柜、动态提示、键盘与拖动流程、量取 HUD 与结果 |
| `scripts/workbench_art.gd` | 试作物品显示别名 → 共用供应品 AtlasTexture 与缓存；不改会话 ID |
| `scripts/workbench_table.gd` | 背景与独立实物、开合、倾斜、填充示意、命中与鼠标手势 |
| `scripts/workbench_liquid.gd` | 独立视觉颜色、混色、液面轮廓与轻微波纹；不参与味觉评分 |
| `scripts/workbench_measure.gd` | 单次黄金区间判定；焦点丢失暂停；确认只发一次 |
| `scripts/workbench_session.gd` | 会话、虚拟库存、容器、动作、单杯结果、原子保存与去重 |
| `assets/workbench/` | 第一人称背景、旧版透明图集存档和生成提示词 |
| `assets/art/supplies/textures/` | 当前实际使用的共用器具、杯型、材料和冰素材 |

本轮保持早先三个接点：project 注册 WorkbenchSession、home 注册 mixing 场景、GameSession 把试作存档纳入备份和重新开始。未更改其他系统的业务 API。

Navigation、`on_drink_served()`、钱包、剧情、酒单、图鉴和音频的行为不因本次出杯而改变。工作台不调用送客回调。04:00 仍按现有逻辑返回主页，试作半成品保留。

每个操作携带命令 ID 和会话 ID。库存、容器、动作、去重凭据在同一快照中提交；文件写入失败不改变内存，同命令重试返回原结果，旧会话不能作用于新杯。每次制作锁定目标配方快照。操作动画只表现已确认结果，不承担第二次扣料。

独立文件：`user://workbench_practice.json`。新增顶层 `table_materials` 保存最多五款、不可重复的桌面材料 ID；旧存档缺省为空，不改变已有库存、容器及动作。摆放通过同一个原子保存入口提交，写入失败不会改变桌面或库存。

withdraw 现在可携带 `vessel` 指定接酒容器；旧调用和旧日志省略时仍按 jigger 处理，旧存档无需改写。直倒同样先校验容量、冰占位和壶盖状态，失败不扣料。杯型替换只更新 cup，不改变容器内容。

旧试作存档新增朗姆与伏特加默认练习数量，已有原料数量、半成品和动作不被重置；旧 rocks/highball 杯型继续可读取，新杯默认 coupe。它是试作存档的兼容补充，不是正式商品或玩家库存迁移。

测试可用 `--workbench-save=/tmp/example.json`；已有 `--game-save`、`--dialogue-save`、`--slot-wallet` 参数也自动派生隔离路径。测试没有读写玩家真实金币或营业存档。

## 两份标准的关系

参考用户提供的《鸡尾酒图鉴接入标准.md》《原料与器具素材接入标准.md》。文档描述的 `data/cocktails/catalog.json`、`data/supplies/catalog.json`、SupplyInventory、SupplyTool 与正式 PNG 已通过合并 fengqiyuan（合并提交 ec3a0a1）进入本分支。v0.3 已让工作台使用其现有美术资源；正式配方、库存、订单的业务联调仍待完成。

已遵守：定义与状态分开、原料与冰分开、酒感不作 ABV、空值不猜测、正式来源不被改写、图鉴可看不等于解锁或上架。已知金酒映射 `sku_gin_london_dry`；其他未知 SKU 保持 null，不据猜测扣真实库存。

正式接入待办：

- 统一唯一库存实例，由 `as_recipe_inventory()` 给图鉴查询；不双重消耗 MenuCatalog 和 SupplyInventory。
- 保留用户确定的“实际取料时扣、容器间转移不扣”，不要与标准中的整杯批量扣料同时执行。
- 在候选库存上 consume，和容器及动作统一提交；不能正式库存先保存而容器后保存。
- ml/g/piece/sprig/dash 分开；未知换算禁止真实扣料，不能因图鉴已有进度就自估消耗。
- 正式配方来源 ID、行 ID、SKU、用冰阶段、杯型、版本应进入会话快照。display_steps 仅展示，不能解析成可执行动作。
- 现已共用标准器具纹理；工作台继续负责桌面绘制与命中。若后续复用完整 SupplyTool 场景，再适配 GrabPoint/PourPoint/FillPoint/GarnishPoint；精确毫升仍归制作会话。
- 订单、接待、交付与钱包一次收款契约到位后再接营业模式；试作完成不能冒充顾客订单完成。

液体颜色由 `workbench_liquid.gd` 的独立视觉配置决定，不由酒感、ABV 或味觉评分计算。碟形杯和直筒杯分别使用弧形液面、圆底边缘、半透明渐变与弯曲高光；倒料采用渐细的曲线液流及小型落点水纹。液面高度是近似表现；本轮没有液体物理、真实融水、分层密度模拟、开瓶盖动画或新增音效。

## v0.6.1 搅拌杯液体反馈修正

搅拌杯现在按独立的内部轮廓绘制液体，修正少量酒液被素材厚杯底遮住的问题。直接倒料时显示逐渐增加的预览液面；量酒器倒入时平滑上涨并混色，过滤时逐渐下降。轮廓、高光和波纹保留，显示不改变实际容量或重复消耗原料。其他容器在填充期间发生变化时，也会从当前可见液量继续动画。

`verify_workbench_mixing.tscn` 新增 12 项检查，覆盖直倒预览、提交、量酒器转移、动画中断连续性、混色、过滤下降及不重复扣料；本轮另通过 31 项拖动和 25 项直倒回归。Godot 实际渲染截图在 `试玩预览/v0.6.1/`，包含空杯、30 ml 金酒、90 ml 混合液三个状态。
