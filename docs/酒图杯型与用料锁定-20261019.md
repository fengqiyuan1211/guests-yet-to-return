# 酒图杯型与用料锁定

提示词版本：`diy-cocktail-selection-locked-v7`。

- 所有杯型使用相同约束流程，不针对某一种杯子或某一种装饰打补丁。
- 从请求实际配方动态构建锁定清单：所选杯型及结构、液体原料及用量、可见装饰和留杯固体及数量、出品冰。
- 在提示词开头、参考图解释之后、最终交付检查前重复同一清单；美观、故事和范例不能覆盖选择。液体原料融入酒液，不能画成未选的水果或叶片。
- 删除要求所有杯子都具备杯脚的笼统文字。颜色、液位与笔触可美化，杯型、杯脚有无和杯身结构不可随意改变。
- 风格图片必须与所选杯型相同，可见食材身份、用量、单位一致，出品冰有无一致；不匹配就不传。规则预览仍优先放在第1张。
- task record 元数据新增 `selection_lock`、`reference_selection_policy` 便于核对实际请求。保留既有人工确认，不宣称完成了自动视觉验收。
- 不修改旧图片、不自动付费重生成。已成功任务仍按原请求ID返回原图，用户点击重新生成时才用新版提示词提交新任务。
