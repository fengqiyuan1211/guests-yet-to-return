# 开篇场景 CG 与演出设计

版本：2026-10-16 概念设计。配套《剧情大纲与逐场文本.md》使用。下列构图、人物外观与交互细节是设计建议。概念图用于选方向；未经确认的图不替换现有游戏资源。

## 一 统一美术方向

保持当前暖色手绘、西部酒馆与海港元素。使用现有木纹、黄铜、羊皮纸和较自然的人物比例。明确排除像素化、降清晰度、廉价霓虹描边、过度金光及塑料感 3D。

现实城市与小岛使用同一种笔触，通过环境与色温区分：城市是灰蓝灯光、玻璃和普通出租屋；岛上是海蓝、木材、绳索与局部暖灯。现代物件允许出现在城市回忆，小岛场景不无故塞进现代屏幕。海港仍应能在抵岛场景辨认出来，不把所有外景直接画成仙人掌荒漠。

主角采用第一人称，不必须展示脸与身体。工作台不加手；拿取物品可用物件位移、轻微镜头变化与音效表达。金融背景不通过名校校徽、豪车、豪宅和满屏数字堆砌。

## 四 逐张 CG 制作规格

### CG01 公寓夜

用途：S01 项目失败、S04 收信。同一背景制作冷光与台灯亮两个状态，减少重复制作。

镜头：坐在桌前的第一人称中景。桌沿占下方约三分之一，电脑偏右，旧配方本靠左，门边纸箱可见但不抢眼。窗外是普通城市夜色。

画面重点：空下来的日程感、生活被打断的痕迹，不表现破坏性行为。项目文件合上，杯子还在。电脑上的文字和邮件提示必须分层，不让生成模型决定台词。

可点物件：项目文件、旧配方本、邮件。点完不反复弹说明框；可选信息轻量显示在既有对话区。

声音：冰箱低鸣、远处车声、一次邮件音。开场可无 BGM；来信段加极轻的旋律，不立刻高潮。

转场：点击附件后，局部配方页与回忆中的同一页对齐淡化。

交付：背景一张、台灯亮层、电脑屏幕遮罩、配方本/文件/杯子道具层、前景遮挡层。没有未经确认的学校或金融机构标志。

### CG02 城市酒吧回忆

用途：S02、S03 的人物对话。

镜头：玩家坐在吧台，富商位于画面右半偏中，左半保留杯子与便笺。雨窗与现代城市轮廓只作背景。和岛上酒馆有相似木质，但不要直接把荒漠门外当作现代城市。

角色表情：平静、好奇、尝后思考、轻笑四种即可。不要大幅夸张惊讶或脸红。

两杯酒：放在同一平面，杯口椭圆和透视一致。回响使用本次已确认的明亮通透蓝色，经典 Last Word 保留原黄绿色；两杯使用相同杯型与相近照明，蓝色不自发光。背景不要同时摆十几瓶抢眼原料。

交互：轻点杯子查看一句笔记。点富商不是自动推进选项；对话与选项沿用一致的阅读规则。

声音：杯底轻触木面、低声背景交谈、雨声。对白出现时音乐略降，不使用每个字都响的打字音。

交付：空背景、富商半身立绘与表情、两杯酒透明层、笔记层。调酒师只需背景弱化剪影，不抢占第三位重点人物。

### CG03 回响的试调笔记

用途：S03 命名、补足两人长期联系，以及 S07 找到更新一页。

镜头：纸页特写，页角的旧划痕是连续性标记；左侧保留半只杯子，右侧有修改记录，不堆满装饰。

交互：翻一页，旧版本变为当前教学版本。暂用图形占位；正式用量和版本从配置读取，避免背景数字与左上角配方不同。

声音：纸张翻动、笔尖短声。两三张便笺的蒙太奇可只做平移与淡入，不必每次切新场景。

交付：空白纸底、页角遮挡、装订/线圈层、可读文本层。文字统一为“回响 / Echo World”，保持独立文字层，便于本地化。

### CG04 海路与码头

用途：S05、S06 开头，可制作同背景远景与靠岸裁切，不强制新增可行走地图。

镜头：从船上望向码头。前景少量船舷，海面位于左中，建筑在右远景，管家小比例站在落脚点。

环境：潮湿木桩、绳索、普通客船、低矮木屋，兼容海港与西部小镇气质。不要热带度假岛、巨型城堡或海盗战舰。

动态：低幅海面波纹、船身缓慢起伏、薄雾层缓移。给减少动态选项保留静态版本。

声音：低频船机淡出、绳索轻响、水声、海风。主题音乐从这里渐入。

交付：远景、码头中景、船舷前景、雾层、管家远景层。外景不强行做日夜全套，先满足清晨抵岛。

### CG05 椅子与门

用途：S06 关键情感镜头；后续经营还可复用。

镜头：门边椅子位于偏左的视觉中心，门占右半；灯在椅子上方但不正对镜头。管家站在门旁，不能挡椅子。

材质：椅面有擦拭和使用痕迹，墙面有盐风痕迹；木头不是整块纯黑，暖光不是金色滤镜。

动态：布巾轻动、门内细微光线变化。椅子本身不发光。玩家查看后仅给短回应，不出现“感动值 +10”。

声音：风、木门轻响、钥匙声。关键对白前让环境声稍留空，不强制每句配煽情乐。

交付：无人物门口背景、灯亮/灭、椅子、门扇前后遮挡、钥匙近景。木牌文字用 UI 层。

### CG06 空酒馆与交接

用途：S07。优先复用 `assets/art/saloon-day-unlit-v2.png` 的大厅构图和材质；现有图含西部荒漠景观，若用于岛上，应确认是否只改门窗外景，不能直接宣称所有海港环境已统一。

镜头：主角站到吧台后，望向客席。眼高、柜台透视要与接下来实际工作台兼容；切换时不要突然变成悬空俯视。

新道具：钥匙、酒谱、简短库存账册即可。主角看见的是可打理的旧店，不是严重坍塌遗迹。

声音：室内木声、远处海风。对白讲解和菜单说明避免同时出现。

交付：原背景引用说明、必要外景变体、管家层、三样道具。不得覆盖原图，只新增版本供选择。

### CG07 第一杯工作台引导

用途：S07 进入工作台、S08 制作。应主要使用实时场景，不用 CG 替代真实操作。

构图：上方左侧配方纸条，右侧备料栏，杯子右上；中央保留操作空间。常用量酒器、摇壶在桌上，轻压棒需要时从菜单取出，用后收起。

高光：目标器具柔和描边；仅首次显示短虚线路径；当拖动正确材料进入目标区域时边缘略亮，离开时恢复。颜色之外另有文本与形状提示。

黄金刻度：只在量酒器里显示实时量和目标红线；直接倒不借教学偷偷出现精确即时刻度。黄金区间不把实际量强制吸附成固定值。

反馈：倒入时液面上涨、薄荷轻压渐碎、摇壶随往复运动变化，沿用已实现的方向；教学只是说明当前目标。错误目标给小幅提示，不大幅红屏。

音效：瓶子玻璃接触、薄荷叶摩擦、轻压闷响、冰块碰撞、摇和与液体倒入分别使用不同声音；循环音随动作停止，切页面立即停止，避免音频重叠。

交付：高光样式、目标锚点、提示栏状态设计；未新增手部立绘。图中的工具数量和位置仅为构图草案，正式按实际工作台布局校准。

### CG08 成品与留下今天这一页

用途：S08 结束。实时成品图叠加背景，保证颜色、杯型、液面、装饰与实际制作一致。

构图：杯子偏中右，下方小面积酒谱页；背景降低对比但仍可辨认。不要用巨大的金色奖杯或“人生重启成功”字样。

反馈：显示本次实际数值和一条易懂建议。酸、甜、漏料与合格使用不同话术。故人研究的剧情身份不影响制作质量评分。

声音：轻放杯子、短确认声；不要每次都播放强烈胜利号角。

交付：成品卡布局、纸页与杯子实时渲染区域、可选备注入口。备注不阻挡开门。

### CG09 翻转营业牌

用途：S09 收束序章并进入主游戏。

镜头：从门内看营业牌，外面露一点傍晚海港光。玩家操作后牌子轻晃，灯亮；镜头回到现有大厅，门铃响。

时间：演出与 TimeManager 正式营业时刻对齐；黄昏美术不意味着可以跳过营业规则。若系统目前到 20:00 才营业，应通过自然时间转场进入。

声音：木牌轻碰、灯具开关、门铃。主题旋律接入大厅 BGM，短交叉淡化，不能两首同时满音量播放。

交付：营业牌双面、门灯状态、门内背景或 CG05 变体。字幕文字单独绘制，便于本地化。

## 五 规格与拆分

建议背景先按 2560 × 1440 输出，游戏逻辑视口仍沿用 1600 × 900。概念图的生成尺寸可能不同，不能把放大后的像素数当成已具备最终画质。

关键人脸、杯子、钥匙与椅子避免放在底部约 25% 的对白覆盖区；超宽或较窄视窗按安全裁切检查。CG07 必须按真实工作台 UI 覆盖检查，不能沿用普通对白 CG 的安全区。

制作分层建议：背景、人物、前景遮挡、交互物件、光效、文字与 UI。背景不烘焙标题、配方量、按钮与提示。每张图同时交付无字底图，人物如需独立立绘再生成透明版本。

新增名称采用 `opening_01_apartment_v1` 等版本化命名；确认前只放设计目录。正式导入才进入游戏 `assets` 目录，并保留来源、提示词、尺寸与使用场景。

## 六 可直接交给美术的提示词基础

统一前缀建议：

> 2D 手绘叙事经营游戏背景，延续既有西部海港酒馆的自然比例、深色木材、黄铜、克制的暖灯与可读的细节。保持画面精致，减少无关摆件，第一人称视角，无前景手部。非像素画、非照片、非塑料 3D、无品牌标志、无烘焙文字。按镜头说明预留对白区，并将重要道具与背景分层。

场景补充：

- 公寓：现代中国城市夜景，安静桌面、项目文件、旧杯子、邮件与配方本；冷灰环境中一点桌灯，不描绘夸张崩溃或财富符号。
- 城市酒吧：雨窗、两杯同杯型鸡尾酒、认真倾听的中年酒友、手写试调本；富商衣着体面但不炫耀，两杯酒均自然通透。
- 码头：低饱和海蓝、木桩与绳索、普通客船、薄雾中的木质小镇、等候的老管家；温和清晨，不做旅游广告。
- 门口：结实旧木椅、未亮的铜灯、半开的酒馆门、自然磨损与干净椅面；重点是有人真的使用这把椅子。
- 工作台：保持杯子右上、量酒器与摇壶常用位置，少量备料，柔和单目标高光，下方浅色操作提示；无夸张魔法光柱。

六格板的完整生成提示词与生成结果另记于同目录 `CG生成记录.json`。仅使用内置图像生成工具；不代表游戏素材已导入。
