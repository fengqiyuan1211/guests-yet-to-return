# 开始界面、序章与第一杯教学：Godot 接入说明

更新：2026-10-16。当前为可运行试玩实现，配方、风味与评分数值仍属游戏参数。

## 怎样体验

使用仓库的 `project.godot` 启动项目，主场景现在是 `scenes/title_screen.tscn`。

- 全新存档：开始游戏 → 序章 CG → 工作台教学 → 出品评价 → 开门 → 米洛首次来访。
- 已有存档：继续旅程会回到原营业流程，不强制重放开篇。
- 已有存档想体验新增内容：开始界面右下角“回看序章 · 练习教学”。结束后返回开始界面，原仓库、金币、半成品、客人进度与小游戏奖励不重置。
- 需要重开：选择“新的开始”，阅读确认窗后才执行；现有进度先备份到存档旁的 `backups/restart-*`。
- 酒馆中的设置新增“返回开始”。离开前保存正常营业进度。

## 已实现的画面与声音

采用 A「归港余晖」，去掉概念图中的烘焙文字，标题与菜单由 Godot 绘制。保留岛屿、木码头、落日与灯的位置。

海面使用局部水域着色器：多尺度波动、近大远小的位移、细小浪尖与夕照反光；岛屿、天空、码头和 UI 不随整屏变形。灯光有轻微明暗变化。不是三维流体模拟，也没有切换为像素风。

配乐沿用用户确认的 **Laura / kaazoom** 原始 MP3，开始界面正常速度播放；进入教学切换既有工作台配乐，进入大厅恢复日夜音乐。另有低音量、24 秒循环的程序合成潮声，受“音效与海浪”滑块控制。声音来源见配乐目录及 `assets/audio/music/README.md`。

设置提供音量与“减少动态”。减少动态关闭水面位移和灯光闪动；窗口失去焦点时不继续累积海面动画时间。

B「留一盏灯」与 C「潮汐来信」概念原件继续保留。`data/opening/backgrounds.json` 预留不同阶段的背景记录，但目前只启用 A，尚未凭未经确认的故事条件自动切换 B/C。B 的无文字门廊图用于抵岛 CG。

## 序章内容与操作

`data/opening/story.json` 接入 S01—S07，共 66 个对白节点：项目结束后的公寓、城市酒吧的旧日回忆、故人来信、抵岛、空椅子与老管家。现有长文设计仍保留为后续润色依据。

本轮用公寓、城市酒吧、夕阳海港、酒馆门廊及既有酒馆背景承载剧情，不把每一句话制作成独立插画。新增美术原件与提示词记录在 `assets/art/opening/`。

- 空格或点击对白：未显示完先显示全文，下一次才推进。
- 两处轻量选择保留回答；选项支持鼠标及键盘聚焦。
- “跳过剧情”进入教学，不直接跳过制作。
- Esc / 返回开始：保存当前节点与选项。
- 教学结束后老管家接话，点击开门接入已有营业时间与接待系统。

本轮无配音、逐角色口型或可自由探索的 CG 热点；演出以背景、淡入、字幕和音乐为主。

## 第一杯：回响 / Echo World

回响使用独立官方配方 ID `echo_world`，当前版本为 `echo-midnight-2`。午夜蓝草本酒是用户指定的虚构高山草本酒，设定为龙胆、当归、柠檬马鞭草、百里香、杜松与极少量薰衣草；草本清香、中段微甜、尾韵微苦悠长。旧称“回声”“ECHO WORD”只作为历史别名；经典 Last Word 仍独立保留，归航 / homeward 未合并。

为使蓝色由共享混色系统产生，新增虚构「午夜蓝草本酒 / Bleu de Minuit」SKU，而不是强行把金酒或樱桃酒改蓝。它具有库存、商店价格、口味与液体颜色数据，后续研发也可使用。

| 原料 | 目标量 |
| --- | --- |
| 伦敦干金酒 | 22.5 ml |
| 午夜蓝草本酒 | 22.5 ml |
| 马拉斯奇诺樱桃利口酒 | 22.5 ml |
| 鲜榨青柠汁 | 22.5 ml |
| 制作方冰 | 150 g，即 3 份，每份 50 g / 4 块 |

使用碟形鸡尾酒杯。液体共 90 ml，当前不额外模拟真实融水体积。顺序为：四种原料各量取 22.5 ml → 加制作冰 → 盖好摇壶 → 有效摇和 6—10 秒 → 过滤入杯。本配方不加入糖浆、薄荷，也不需要轻压步骤。

等量配方已按用户给图确认；钴蓝色强度、180 金币/瓶的试玩价格及风味数值仍是游戏配置，不是现实饮用或商品规格的定稿。

## 教学如何接入工作台

复用原来的拖动、量酒器空格判定、轻压、摇和、过滤、出品和评价代码。引导根据实际杯中内容、动作日志及有效时长推进，不伪造一杯成品，也不自动将偏差纠正到配方值。

提示包含下一步文字、右侧材料分类切换及目标高光；量酒器目标红线读取同一配方快照。若直接倒入、超量或倒掉，按实际操作保留结果；按 N 可重新准备教学包。

教学包与正式仓库完全独立。一次原料取出只扣教学包，量酒器转移不再扣；同一操作编号重试不重复消耗。教学不会收款、写顾客满意度或推进来访章节。跳过教学也不会生成虚假的完成记录。

实际完成后可查看酒液外观、品质及属性，选择重练或继续开门。回响只解锁到图鉴，不自动加入营业酒单；正式营业原料仍需购买。

兼容说明：之前的蓝橙试调方案已撤回，商店不再上架；旧 SKU 只保留用于读取旧库存、半成品和配方快照。新版回响不使用它。正在制作的旧教学杯不会被静默改配方，按 N 可重做为新版；新建教学直接使用午夜蓝版本。

前一版联调同时修正了过滤草本的评价（新版回响不含薄荷，不需要该步骤）：将实际参与轻压、混合的薄荷贡献随酒液转移，过滤后没有叶片也不会被误判为没加薄荷。遗漏轻压仍会扣分；部分倒出按份额保留贡献，丢弃不会反向计入成品。未完成的旧杯继续保留各自的配方、颜色和评分配置快照，已保存评分不重算。

## 存档与模块边界

| 模块 | 职责 |
| --- | --- |
| `OpeningFlow` | 最先加载，区分新档与旧档；存序章节点、选择和教学快照；切换回看上下文 |
| `title_screen` | 开始、继续、设置、回看、新旅程确认 |
| `opening_story` | CG、字幕、选择、结尾与教学入口 |
| `opening_tutorial` | 观察当前制作记录，只控制提示和高光 |
| `WorkbenchSession` | 原制作指令；仅教学状态把提交路由到独立教学存档 |
| `Supplies` | 正式库存保持原有事务逻辑 |
| `TimeManager` | 标题、CG、教学暂停营业；进入正常酒馆恢复 |
| `SaloonAudio` | 同一套音频管理器处理标题、教学与大厅切换 |
| `MenuCatalog` | 以官方 ID 幂等解锁回响；不自动上架 |
| `GameSession` / `home` | 接续已有接待；新旅程首次开门安排米洛 |

序章进度放在原 GameSession 路径旁的 `.opening` 文件。教学容器、动作、操作回执与教学原料余量在同一个 JSON 中，写临时文件后原子替换，避免只扣料没保存杯子。教学退出时将工作台恢复为正式仓库内的原半成品；再次进入教学恢复它自己的杯子。

回看使用独立 `.replay` 文件和运行时上下文，退出时恢复正式序章状态；不会重新发配方。回看中直接关闭程序，下次仍从正式旅程开始；不恢复中断的回看。

损坏的序章记录不会被当作新档覆盖，会显示错误。正常“继续”也检查正式存档的可写状态。新旅程重置扩展原有备份流程，包含序章文件。

## 验证与当前限制

独立 `/tmp` 存档中验证了：全新标题退出后仍进入序章、旧档继续且核心文件不变、节点/选择恢复、实际调制、重复扣料防护、跨进程杯子与库存恢复、失败写入回滚、恢复原半成品、正确摇和/过滤的评分、回看隔离、开门后米洛接待。

命令：`python3 tests/run_opening.py --godot /path/to/Godot --graphics`。另运行既有营业/自由调酒/手帐集成、液体、出品、库存、统一口味及音频路由测试。图形模式检查了标题、CG、教学和成品卡布局；没有改动用户的真实存档来做测试。

已对齐两条旧评分测试断言：原断言仍期待旧的未经校准口味数值，现改为项目当前统一感官模型的标准值；经典酒谱用量未因此修改。

本机此前出现 CoreAudio 输出设备启动失败。重新连接当前外置耳机并重启游戏后，独立 CoreAudio 检测的混音时钟恢复推进，新游戏及最新图形回归日志不再报告该错误；实际听感仍由玩家确认。部分无界面回归仍有退出时 ObjectDB/资源释放提示。

下一步适合根据试玩继续调整：海浪幅度和浪声比例、字幕节奏、教学容错范围、正式开局备料平衡、蓝色回响实际口味、B/C 阶段解锁条件，以及更多角色/细节 CG。

## 动态教学指引与首页铃音（2026-10-16）

- 首页按钮悬停播放原创轻柔星光音（已弱化敲击起音和金属泛音，较首版约降低 8.3 dB），沿用 SFX 音量；鼠标停留不重复触发，260 毫秒节流，最多两个尾音，禁用按钮与失焦窗口不播放。生成源在 `tools/build_title_chime.py`。
- 教学按真实制作状态显示呼吸光框、模拟点击光标、带箭头的拖动路线、起点与落点标签。材料菜单会定位并滚动到当前目标。
- 玩家开始拖动后隐藏示范光标，只保留落点提示；量取中改为大号空格键提示，进入推荐用量范围时显示“现在按空格”。
- 摇和实时显示有效秒数（包含本次尚未松手的操作），达到目标后提示松手；完成一杯时先指向成品杯，再提示空格。
- 指引层不拦截鼠标，不替玩家加料、扣库存或改分。打开其他弹窗时隐藏，出品评价窗口不覆盖；沿用“减少动态”设置，改为静态图示。
- 同时修复序章按键切换场景后访问已移除视口的问题。
- 图形回归：90 + 57 项检查通过，另验证旧存档和首次启动识别。新增检查覆盖引导层不拦截操作，以及量取弹窗中的空格提示。
