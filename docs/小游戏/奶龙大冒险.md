# 奶龙大冒险 · 第一版

## 如何试玩

Godot 打开工程，重新运行。入口：手帐 → 黄色生物 → 专属小游戏 → 奶龙大冒险。
内测直接开放，不要求先完成五次对话，也不改变正式剧情解锁状态。
也可打开 `scenes/yellow_ski.tscn`，按 F6 单独运行；退出会进入酒馆主页。

- 鼠标点画面、空格、W、↑ 或右下角按钮：跳跃。
- 在空中持续按住：向后翻转。出现“松手，准备落地”后放开，落地有一定辅助修正。
- 完整翻转且落稳：加分和短暂加速。翻转后没站稳则减速。
- Esc / 暂停：停止雪崩和滑行。失去应用焦点也会暂停。
- 跳过石头和倒木，收集雪星，滑过 2,000 米获胜。正常路线约 82 秒。
- 障碍会降低速度；撞击后的短暂保护避免同一障碍连续扣速。
- 被雪崩追上失败，可立即重新开始。

## 与主游戏的边界

进入时记录并暂停酒馆时钟，返回时恢复原来的运行状态。保留客人、对话、酒杯、库存、金钱。
现阶段不消耗金币、不发放配方或剧情奖励。游戏内雪星是小游戏得分，不是酒馆金币。
每局结束保存最远距离、最高得分和最高翻转次数到 `user://yellow_ski.cfg`，中途退出不记本次纪录。
通过临时文件写入后替换纪录文件；写入失败会在结算提示，不影响重玩。
该纪录独立于营业周目。重开酒馆不清空滑雪最高纪录。

## 文件

- `scripts/yellow_ski_model.gd`：固定 120 Hz 步长的运动、碰撞、追赶、计分与胜负。可独立测试。
- `scripts/yellow_ski_canvas.gd`：原创程序绘制的山峰、雪坡、树、障碍、粒子、视差与角色展示。
- `scripts/yellow_ski.gd`：输入、暂停、结算、纪录与时间恢复。
- `scenes/yellow_ski.tscn`：Godot 场景入口。
- `assets/minigames/yellow_ski/rider.png`：透明背景角色与牛滑板合成素材。当前是单张精灵，通过转角、压缩回弹和粒子表现动作，尚未拆骨骼。
- `data/guest_activities.json`：黄色生物的试玩入口。
- `tests/verify_yellow_ski.gd`：31 项隔离回归检查。必须传入隔离存档路径及 `--ski-verify`，不要对真实玩家存档运行。

## 关键校准

路线长 60,000 世界像素，30 像素显示为 1 米。跳跃相对于当前坡面速度，重力 880，跳跃冲量 500，翻转角速度 8.5 rad/s。
普通跳跃不必翻转即可过关。翻转是可选的得分技巧。落地朝向偏差阈值 1.05 rad。
计分：雪星 20；完整翻转 150×圈数×连击（最多4倍）；距离每米1分；通关另加2,000及最多500的少碰撞奖励。
