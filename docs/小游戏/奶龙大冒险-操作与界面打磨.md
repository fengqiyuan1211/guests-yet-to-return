# 奶龙大冒险：操作与界面打磨

## 操作

- 点击、触摸或 Space / W / ↑：起跳。
- 空中继续按住：经过 0.12 秒准备后逐渐起转；最高转速 10.8 rad/s，加速度 38 rad/s²。
- 松开：90 rad/s² 制动；下落时收稳到最近的雪坡方向。自动收势不会累计翻滚圈数。
- 落地前 0.16 秒内按下跳跃，落地后接上下一跳。
- 按 Esc 暂停；失去焦点自动暂停。

## 翻滚与落地

- 空中绕身体中部旋转，替换原来绕牛板底部甩圈的表现。
- 起转时轻微收身，落地时压缩回弹，附带雪花与短轨迹。
- 空中显示圈数和旋转进度；接近地面提示松手收势。
- 完整圈数只有安全落地后才计分。
- 落地与坡面的夹角误差大于 1.05 rad 仍会摔倒；小于 0.30 rad 为完美落地。
- 每圈基础 150 分，连续成功落地倍率最高 4；完美落地额外 50 分。
- 稳定落地加速 2.5 秒，完美落地加速 3.1 秒。

## 界面

- 顶部拆分旅途距离、得分、身后雪崩距离与加速状态。
- 路程条和加速条使用固定高度绘制，避免默认进度条主题撑大。
- 右下按钮随状态显示“轻点跳跃 / 按住翻滚 / 松手收势”。
- 开始页展示角色和三步操作说明；暂停与结算时隐藏跳跃按钮。
- 结算页显示滑行距离、得分、翻滚落地数、最长连续落地数。
- 继续使用 1600×900 逻辑布局，随窗口等比缩放。

## 保持的流程

手帐入口、2000 米路线、原有背景音乐、音量设置、最高纪录保存方式和退出后恢复酒馆时钟均沿用。不会消耗金币、改动剧情或桌上的酒。

## 验证

`tests/verify_yellow_ski_polish.gd` 包括 41 项检查：整条路线、起转制动、落地缓冲、翻滚计分、危险落地、鼠标/触摸、暂停和退出恢复。须使用隔离存档和 `--ski-verify`，不要直接用真实存档运行测试。
