# 评分机制核对与修复记录

日期：2026-10-05。依据：逐节核对《客人偏好与酒品评价机制-数据与判定规范-v0.1.md》及实际代码、配置。本文覆盖评分服务与其交付接入；羽毛球、界面和章节聚合另有整流程验证。

## 结论与本次明确变更

**目前不能宣称完全符合整份规范。** 已修复现存四维评分、必要数据失败、硬限制、规则冻结、普通 Buff 与旧订单兼容。统一标准杯、酒单推荐、完整过程感官模型、传说共鸣及通用剧情触发仍未完成。

本次用户追加要求优先于旧文档建议：

- 普通配方标签 Buff 也必须来自**真实完美制作**。采用工作台 `evaluation.tier == "perfect"`，同时校验真实配方来源、授权版本；单有 95 分或复制名称、图片、标签均不够。旧 §6.2“普通 Buff 不一律要求完美”及 T28 的独立 10% 剂量建议未作为本次规则使用。
- 小线偏好清爽 +5、气泡 +5、杜松 +3，普通加分总上限 10。其余人物原有策划数值、图鉴目标不变，未配置亲和度默认 0。
- 隐藏剧情使用固定五段对应正式交付的**最终满意度** `review.satisfaction` 的平均分，达到 60（含 60）准入，计入 Buff 与扣分。拒收的满意度仍存 `null`，章节聚合按 0 且占一次；未知必要数据导致未成功交付，不伪造评分。不能再把门槛写成制作质量均分。
- 《童年拾忆》纪念纸配方和传说 Buff 仍留空；没有虚构传说奖励或 +100 共鸣。

## 已修复的现存问题

1. 新版满意度参数集中于 `settlement_rules.json.scoring`：惩罚系数 2、满意阈值 70、软状态扣分上限 20、普通 Buff 上限 10。内部保留浮点，69.6 不会先舍入成 70 再判满意；星级也按未舍入总分判断。
2. 按规范计算容差后的加权误差；保存每项有效误差与 `deduction`。本地对白按最大有效扣分选主因，满意但有轻微偏差仍表达整体合心意。
3. 同一软扣分去重组取命中项中最严重扣分，规则排列不能改变结果。新版超时是独立既有游戏规则：软状态最多 -20，超时另 -10，合计最多 -30，单列 `timeout_penalty`。旧锁订单保持原先合并封顶的旧语义。
4. 真实杯只统计成品容器内的液体、固体及装饰，别名映射为 SKU；相同 SKU 在不同组成类别中的数量相加，避免字典覆盖漏掉硬限制成分。空杯、负数、字符串数量、未知必要液体／固体不产生正常评分或销售意图。
5. 新版使用真实正体积分母，不以极小分母或最少 20 ml 偷改浓度。糖的现有试玩贡献系数也集中配置；完整溶解／释放过程尚待迁移，见下表。
6. 含酒事实采用 `true / false / null`。任一确定含酒成分使成品为 true；全部确认无酒才为 false；其余为未知。ABV 未填写不影响已知含酒判断，酒感 0 不代表无酒精。黄色生物既有“无酒精”限制在新版适配为真实含酒事实限制，不改其四维目标。
7. 硬限制先于加分；拒收满意度为 `null`、正向加分为 0；必要事实未知返回 `data_incomplete`。未记录的接触来源或操作范围不伪装为已通过。缺数据失败发生在交付账本和钱包入账之前。
8. 普通 Buff 采用稳定 ID、五款经典配方白名单及版本授权。授权取与真实工作台一致的 `MenuCatalog.get_recipe` 快照，授权副本设为合法制作时的 `unlocked=true`，不修改库存或目录。来访时尚未买齐原料、随后解锁选酒不会产生错误哈希拒绝。DIY 不因复制标签获得这些经典资格。
9. 气泡 Buff 同时检查实际碳酸成分，以及完美工作台轨迹的 `carbonated > 0`、`flat == 0`。挂有气泡文字标签或轨迹单独声称有气泡均不够。有效列表与失效原因完整存储，重复 Buff ID 只加一次。
10. 普通奖励按当次亲和度合计后封顶；保存原始加分、实际加分、有效 Buff 名称与原因。满意度可为 110，旧记录校验不再把满意度限制到 100；工艺分仍为 0—100。
11. 来访保存完整评分／感官／原料事实／Buff 规则快照，交付读原快照，不随界面打开或全局配置变化重算。有效成品仍从权威工作台结果读取并校验摘要。
12. `settlement_rules_legacy_v1.json` 是本次切换前原配置的原样归档。缺规则快照的旧锁订单一次性绑定该已知来源，保存迁移标记，保留原需求、报价、开始时间及原杯。旧已结算记录不重算；没有新增字段的合法记录仍可读。不能证明的旧接触历史保持未知。

## 标准属性差异仍需正式迁移

顾客感官使用独立实际杯模型；旧工作台工艺展示仍有“配方目标＋材料偏移”，研发还有原有模型。统一切换图鉴与实际值尚未完成。

已确认的例子：金汤力真实 50 ml 金酒＋150 ml 汤力水得到 35／25／20／30，与其旧目标吻合。莫吉托旧确认目标为 40／35／45／0；按现有液体比例及糖试玩贡献计算约为 42.5／14.966／76.190／0.959，与目标不同。遗言约为 98.389／44.345／100／14.605，旧目标 65／45／65／20。后两者只是当前模型对配方比例的对照，**不冒充经过容量、冰与真实标准操作的完整标准杯生成结果**。

需要公共模型校准、完整标准杯生成与差异审阅，再一并切换图鉴、推荐和研发；本次没有为了凑一致而覆盖莫吉托来源确认值。
