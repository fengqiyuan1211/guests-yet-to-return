# 传说吧勺「我是奶龙」

2026-10-18。物品 ID：`tool_yellow_bar_spoon`。

## 获取与使用

- 黄色生物正式剧情邀请解锁滑雪后，滑到终点 2000 米即获得；失败不发，重复通关不重复发。
- 永久器材，非开局赠送、非商店商品；背包金色边框与“传说”文字。
- 调酒台「器具」栏优先显示。点击选用或拖到打开的成品杯/搅拌杯/摇壶，继续沿用原有搅拌操作。普通吧勺仍可选择。
- 沿用普通吧勺制作判定，没有增加评分、口感、消耗或金币加成。
- 物品所有权在 `supplies_state.json` 的 `inventory.items.tool_yellow_bar_spoon`；当前杯选用的皮肤保存在同一文件的 `workbench.session.spoon_tool_id`。
- 发放通过库存原子写入，成功保存才发布所有权；保存失败可在结算界面重试，返回/重新滑行前也会重试。

## 旧版通关兼容

启动时读取 `yellow_ski.cfg`。旧纪录达到 2000 米且当前存档已解锁正式邀请时补发。检查后记录 `legendary_spoon/migration_checked`，避免重新开始游戏后被旧的历史最高纪录再次赠送。

## 美术接口

- 原图：`assets/art/supplies/equipment/yellow_bar_spoon.png`，保留用户选中的原始透明 RGBA 图片。
- 紧边距资源：`assets/art/supplies/textures/yellow_bar_spoon.tres`，AtlasTexture，region `(340,12,359,1502)`。
- 可操作道具场景：`scenes/supply_assets/yellow_bar_spoon.tscn`，底部原点、GrabPoint/WorkingPoint，支持与普通器材相同的拖动/倾斜接口。
- 插入杯内时单独处理图像方向：脑袋朝上、肚皮勺头向下；不翻转普通吧勺。
- 使用内置 imagegen 生成。复用提示词：参考黄色生物原角色，小脑袋、绿眼睛、呆滞小嘴、牛仔帽红围巾；细长直脖子当勺柄，压扁的梨形肚子作为下端凹勺面，两只小手贴边、小脚在底部。手绘墨线、水彩和彩铅质感、哑光黄色，完整单一道具，透明背景，无文字。必须保留角色身份和细长可操作的轮廓。
