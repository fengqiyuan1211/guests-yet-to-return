## 评分核对

当前正式顾客评分：

```
每项有效误差 = max(0, |实际属性 - 当次目标| - 容忍度)
加权误差 = Σ(有效误差 × 权重) / Σ权重
基础分 = clamp(100 - 2 × 加权误差, 0, 100)
总分 = clamp(基础分 + 有效普通Buff奖励 - 软性状态扣分 - 超时扣分, 0, 100)
```

目标来自基础偏好＋本次剧情修正，订单冻结后使用该次快照。普通Buff资格由真实工作台完美制作与配方来源确认，奖励总上限10；传说加分保留为0。当前超时扣10，软性扣分上限20。工艺品质不直接乘入口味总分。顾客“满意”阈值70与“小游戏邀请”均分大于60是两个不同用途的阈值。

验证了文档示例：87.5基础＋10奖励＝97.5；100基础加奖励仍封顶100；超时扣分后再聚合。对外仍只显示总分，不添加“偏好＋10”或扣分检查入口。
