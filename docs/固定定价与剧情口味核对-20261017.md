# 固定定价、隐藏小游戏与剧情口味核对

## 本次规则

- 成品售价 = floor(配方原料与装饰成本 × 1.5)，最低1金币。沿用原有取整方式。
- 冰、杯型、器材不计成本；倒洒、重做不抬高售价。经典、角色特调与DIY采用同一计算函数。
- 酒单不再提供改价按钮；读取旧酒单和保存酒单时按固定价校正，DIY修订用料后刷新上架价。
- 已完成订单凭据不重算。正在接待、已经锁定的旧订单保留当时价格；新接待使用固定价格。
- 保留小费接口和当前小费规则：剧情模式90分以上20%、70分以上10%，按现有规则执行；调酒模式保持匹配及制作分结算，不额外修改。
- 五位角色取消未解锁演示入口。手帐未解锁的小游戏标题／页签为“？”，不可点击，也不显示内容或解锁阈值。
- 已解锁后可从手帐进入；正式奖励仍仅发一次。小线处于正式邀请时从手帐进入也使用正式挑战上下文。
- 设置中的“童年球场·练习”移除；旧演示路由禁用，正式小游戏路由检查解锁条件。

## 剧情短期偏好

实际目标 = clamp(基础偏好 + 长期修正 + 当前剧情事件修正, 0, 100)。本轮没有加入长期偏好成长。
事件在来访创建时按章节确定，整个接待保持快照；切换页面或恢复同一次接待不重新叠加。新章节重新从基础值计算，不累计上一章短期变化。
