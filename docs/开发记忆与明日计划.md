## 已确定的设计

- 游戏暂定名：`致未归的客人`
- 类型：2D 酒馆模拟经营游戏
- 目标平台：电脑优先，同时兼容手机横屏和平板
- 引擎：Godot 4.7.2，Compatibility 渲染模式，GDScript
- 视觉方向：西部牛仔酒馆，木纹、黄铜、羊皮纸、暖色油灯、手绘卡通感
- 核心原则：调酒流程尽量接近现实；玩家保存的 DIY 配方应当可以在现实中照着复现
- 角色需求通过主页下方的聊天框呈现。聊天框占用目前“落座吧，今晚的好酒由你来调”标语的位置，显示客人的口味、忌口和当前对话。
- 酒馆可以加入一个独立老虎机小游戏，作为轻松的可玩功能，先做成可以直接操作和结算的简单版本。

### 预定的老虎机经济参数

- 每次旋转成本：20 金币。
- 三个转轮独立抽取，符号权重暂定：`发 3%`、`金币 7%`、`酒杯 20%`、`星星 30%`、`柠檬 40%`。
- 三个相同符号的奖励：
  - `发 发 发`：2000 金币，100 倍投入，作为大奖。
  - `金币 金币 金币`：400 金币，20 倍投入。
  - `酒杯 酒杯 酒杯`：160 金币，8 倍投入。
  - `星星 星星 星星`：80 金币，4 倍投入。
  - `柠檬 柠檬 柠檬`：40 金币，2 倍投入。
- 正好两个相同符号也给小奖：`发 120`、`金币 50`、`酒杯 30`、`星星 18`、`柠檬 12` 金币；三个相同优先结算三连奖励。
- 其余组合奖励为 0。
- 按独立转轮和上述权重计算，平均每次返还约 `16.93` 金币，投入 20 金币，平均每次净亏约 `3.07` 金币，长期返还率约 `84.6%`，满足期望为负。
- 这个数值是第一版经济草案；后续结合玩家平均每天收入、老虎机可见频率和试玩体验调整，但必须保持长期返还率低于 100%。
- MVP 范围不变：主页、营业、顾客订单、调酒、图鉴、商店、研发、酒单、库存、玩家定价、评分和存档
