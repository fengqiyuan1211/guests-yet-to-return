# 图鉴墨线素材库

本库提供透明背景的独立 SVG，供西部牛皮纸风格的图鉴复用。素材使用细褐色墨线 `#775331`，不包含背景、文字或外部引用。

## 卡片小枝装饰

`decorations/` 内素材为 **160 × 200**，墨线透明度为 0.53–0.56。放在卡片酒图后侧的装饰层，并限制在酒图区域，避免进入名称、风味标签和描述的文字区域。

| 文件 | 内容 | 适用线索 |
| --- | --- | --- |
| `herbal.svg` | 淡雅草本小枝 | **默认装饰**；草本香气或未指定风味 |
| `mint_citrus.svg` | 薄荷与青柠角 | 薄荷／青柠 |
| `citrus.svg` | 柑橘枝叶与切面 | 柑橘 |
| `cherry.svg` | 樱桃枝叶 | 樱桃 |

装饰仅作为卡片酒图的视觉衬托，不能自动作为配方用料或装饰物的库存依据。**详情页的风味标签仅显示文字，不放植物图。**

## 器具与杯型图标

`tools/` 内素材为 **64 × 90**，透明背景，墨线宽度为 1.3–1.7，统一圆角收笔。作为独立图标使用，不在 SVG 内嵌入名称或数量。

| 文件 | 名称 |
| --- | --- |
| `jigger.svg` | 量酒器 |
| `muddler.svg` | 轻压棒 |
| `bar_spoon.svg` | 吧勺 |
| `shaker.svg` | 摇壶 |
| `strainer.svg` | 滤器 |
| `mixing_glass.svg` | 调酒杯 |
| `highball.svg` | 高球杯 |
| `coupe.svg` | 碟形鸡尾酒杯 |
| `balloon.svg` | 球形杯 |

`coupe.svg` 可用于通用鸡尾酒杯或碟形杯的展示；展示共用图标不决定杯型解锁规则。回响的碟形杯仍以草案状态为准。

SVG 使用原生路径，不依赖图片生成服务、字体、滤镜或外部资源。
