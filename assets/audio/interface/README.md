# 界面与物品音效

2026-10-06：物品点击改为录音剪辑与短拟音组合。当前共 13 类，每类 2 个取用版本、2 个购买成功版本，共 52 个 WAV，位于 `foley/`。普通导航按钮仍使用 `click.wav`。

| 物品 | 声音方向 |
| --- | --- |
| 普通基酒、利口酒 | 玻璃瓶相碰的短脆响 |
| 苦精小瓶 | 更短、更亮的小瓶碰声 |
| 果汁、糖浆瓶 | 较低沉的瓶身接触声 |
| 汤力水、苏打水、可乐 | 瓶声加轻颗粒质感；点击不会假装打开瓶盖 |
| 薄荷叶、薄荷枝 | 柔和沙沙声；来源是芦苇席摩擦拟音，不是薄荷实录 |
| 砂糖 | 真实倒糖录音的短片段 |
| 青柠角、柠檬片 | 柔软接触拟音 |
| 樱桃 | 更短、更轻的果料接触拟音 |
| 各种杯子、搅拌杯 | 真实玻璃杯轻碰，不同杯型略微调整音高 |
| 摇壶、量酒器、滤冰器、吧勺、盖子 | 真实餐具接触；各器具通过配置微调音高 |
| 轻压棒 | 木质闷响拟音；连续下压仍用独立的轻压接触声 |
| 方冰 | 真实冰块进入杯子的脆响 |
| 碎冰 | 更密、更细的冰粒组合声 |

其中 6 份外部源录音均为 CC0。作者、原页、下载地址、许可、原始文件校验和、成品校验和及加工方式见 [foley/sources.json](foley/sources.json)。果料、木质接触与购买金币尾音含项目原创合成；气泡与碎冰音效为组合拟音，不标称对应商品实录。

## 统一接入

- `data/audio/item_foley.json`：SKU 与工作台短 ID 的映射、13 类声音、杯具/工具音高。32 个现有库存目录条目及额外的冰块、旧式杯型均有映射。
- `SaloonAudio.ui.product(item, purchased)`：商店选商品及事务成功回调。成功版包含对应材质声和金币尾音；失败不会播放成功声。
- `SaloonAudio.ui.item(id)`：工作台备料柜抓取、桌面瓶子、杯身及棒柄/勺柄。抓取时响应，松手不补普通按钮声。加冰、换杯、加配料完成时也按物品反馈。
- `audio_item` 按钮元数据：仓库商品卡片。普通按钮无该字段时继续使用通用轻点击。
- 工作台备料按钮设置 `custom_audio=true`；商店商品与购买按钮也自行处理声音，防止叠加通用点击声。
- 同一种声音 75 ms 内只播放一次，避免同步取放叠响；连续操作交替使用两份片段并轻微变化音高。最多 8 个短音并发。
- 全部接入 SFX 总线。静音设置通用，失焦会停止当前声音并拒绝新声音。音效没有库存、金币、订单的写权限。

## 复建与验证

macOS 可运行 `python3 tools/build_item_foley.py --cache /tmp/item-foley-sources` 下载文档中的 CC0 源文件并使用系统 afconvert 复建。原始文件只放缓存，游戏保留短剪辑。根目录原有合成 WAV 暂留作复建输入及旧资源兼容，不用于新版物品映射。

`tests/verify_item_foley.tscn` 覆盖目录与别名、片段解码、交替播放、防叠响，以及原生备料柜、桌面、冰块、棒柄、仓库点击/拖动与库存一致性。`tests/verify_scene_feedback.tscn` 覆盖商店选择、成功和失败购买、静音及切换。均需隔离 `/tmp` 存档参数，不能使用玩家存档。

场景 BGM 仍由 `SaloonAudio.acquire_scene(owner, context)` 管理，配乐与许可见 `../music/credits.json`。这次只调整物品音效。
