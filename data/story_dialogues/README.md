# 游戏对白数据

`manifest.json` 按来访顺序登记正式剧情，`file` 相对于本目录。

- 小线：`stick/01.json` 至 `03.json`，提交演示版为三次来访，第三次收束到“致未归的客人”。
- 米洛、艾达、老霍克：各五次来访。
- 黄色生物：`repeat.json` 及 `02.json` 至 `05.json`，五次口味旁白，之后使用基准口味。

首次见面的招呼与身份揭示来自 `../guest_introductions.json`，不额外占用剧情轮数。`nodes` 为对话节点，`entry` 为入口，`choices[].next` 或节点的 `next` 指向后续节点；确认带 `transition` 的收尾节点才算完成本章。对白结束后进入闲聊，下一次来访才推进下一章。

章节 ID、节点 ID 和选项 ID 用于存档，变更时需要迁移。小线三轮版保留 `stick_01`、`stick_02`、`stick_03`，旧版已完成轮数最多映射为三轮，未完成的修订章节重新从入口开始，历史对白和既得奖励保留。

正式小游戏邀请读取 `scripts/story_activity_gate.gd`：每个正式章节对应一次已结算送酒，平均总评分严格高于 60。小线为三杯，其他客人为五杯；拒收记 0 分，调酒练习及重复来访不能替换首次章节评分。

剧情进度保存在 `user://story_progress.json`，营业统一快照保存在 `user://game_session.json`。启动时以有效营业快照恢复当前接待，测试必须使用临时存档路径。
